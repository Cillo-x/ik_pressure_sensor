# 运行与部署

本文面向在 Linux / ROS 2 环境运行本驱动。协议与数据域见
[01-485协议与数据域.md](01-485协议与数据域.md)。

## 1. 串口设备

- USB-RS485 适配器在 Linux 下枚举为 `/dev/ttyUSB*`，编号随插拔顺序变化，
  正式部署建议用 udev 规则固定名字。规则文件随包安装，位置在
  `share/ik_pressure_sensor/udev/`：

  ```bash
  # 先按文件内注释填好 idVendor / idProduct / serial
  sudo cp "$(ros2 pkg prefix ik_pressure_sensor)/share/ik_pressure_sensor/udev/99-ik-pressure-sensor.rules" /etc/udev/rules.d/
  sudo udevadm control --reload-rules && sudo udevadm trigger
  ```

  `idVendor` / `idProduct` 用 `lsusb` 查，序列号用
  `udevadm info -a -n /dev/ttyUSB0` 查。

- 串口权限：运行节点的用户需在 `dialout` 组，重新登录后生效：

  ```bash
  sudo usermod -aG dialout $USER
  ```

- 同一个串口不能被两个进程同时打开；调试工具与节点不要同时占用。
- 适配器热插拔、设备名变化时，节点会关闭端口并按 `reconnect_interval`
  重连，不会退出。

## 2. 参数与启动

默认参数在 `config/pressure_sensor.yaml`，launch 文件随包安装：

```bash
ros2 launch ik_pressure_sensor pressure_sensor.launch.py port:=/dev/ik_pressure_sensor
```

- 使用自定义参数文件：`params_file:=<绝对路径>`
- 多实例：`namespace:=sensors`，话题变为 `/sensors/pressure`
- 无硬件调试：`ros2 run ik_pressure_sensor pressure_node --ros-args -p use_mock:=true`
- `baudrate` 与 `slave_id` 必须与设备实际配置一致，取值范围见协议文档

## 3. 轮询与超时

- 默认 `poll_rate` 2 Hz、`timeout` 0.25 s、`retries` 2
- 单次读取最坏耗时 `timeout × (retries + 1)`，默认 0.75 s；读取在独立线程执行，
  不阻塞 executor，期间 ROS 侧照常响应
- 半双工总线同一时刻只允许一个主站：若总线上已有 PLC 等主站轮询，需停用其一
- 气压变化缓慢，轮询频率不必高于 5 Hz

## 4. 断线与诊断

节点以 1 Hz 发布 `/diagnostics`，条目名为 `<node>: link`：

| level | 条件 |
|---|---|
| `OK` | 已连接且连续失败数为 0 |
| `WARN` | 连续失败数 ≥ 1 但小于 `offline_threshold` |
| `ERROR` | 未连接，或连续失败数 ≥ `offline_threshold` |

诊断值包含 `port`、`baudrate`、`slave_id`、`poll_rate`、`timeout`、`attempts`、
`product_model`、`software_version` 以及各类计数器与 `last_error`。

通信失败时不发布旧值或 0，只更新计数器并在状态变化时记录日志；串口本身异常时
关闭端口并按 `reconnect_interval` 重连。设备拒绝请求（异常帧）不重试。

## 5. 数据有效性

- 只有地址、功能码、字节数、帧长与 CRC 全部通过，且数值落在合理量纲内，才采信这一帧
- 气压为绝对气压，单位 Pa；温度按 int16 解释，可为负
- 消息中的 `variance` 固定为 0.0：设备不提供不确定度估计
- 读数存在抖动，对精度敏感的上层可做滑动平均或一阶低通
- 需要整体偏移时使用 `pressure_offset_pa`，该值会加到每次测量上

## 6. 排障

| 现象 | 排查方向 |
|---|---|
| 一直报 `cannot open <port>` | 设备是否存在、用户是否在 `dialout` 组、端口是否被其他进程占用、udev 规则是否生效 |
| 无响应或持续超时 | `baudrate` / `slave_id` 是否与设备一致，总线是否可达 |
| 诊断中 `crc_errors` 增长 | 波特率偏差、线路质量或干扰 |
| `device rejected the request` | 寄存器或功能码不支持 |
| 数值与预期不符 | 确认单位为 Pa、确认是绝对气压、确认 `pressure_offset_pa` |
