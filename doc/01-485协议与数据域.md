# 艾克姆 RS485 气压变送器 —— 485 协议与数据域说明

> 依据：厂家《导轨式 MODBUS 气压变送器使用说明书 V2.1》，以及厂家随附的实测报文
> （`4、USB转RS485转换器串口调试助手读取气压/MODBUS通信.txt`）。
> 文中标注 **【实测】** 的内容来自报文抓取，说明书里没有写；标注 **【待确认】** 的需要在实机上再验证。

## 1. 物理层

| 项 | 内容 |
|---|---|
| 接口 | RS-485，半双工，两线（A / B） |
| 协议 | Modbus-RTU |
| 供电 | DC 5 ~ 30 V（防反接），**独立于 485 总线** |
| 接线端子 | 4 位可插拔端子，间距 5.08 mm |

端子定义（面向接线端子，从左到右）：

| 序号 | 信号 | 说明 |
|---|---|---|
| 1 | VIN | 电源正极，5~30 VDC |
| 2 | GND | 电源负极 |
| 3 | A | RS-485 总线 A |
| 4 | B | RS-485 总线 B |

## 3. 帧格式

Modbus-RTU 帧结构（无起始/结束符，靠总线静默时间界定帧边界）：

```
+--------+--------+------------------+--------+--------+
| 地址    | 功能码  | 数据域            | CRC 低  | CRC 高  |
| 1 byte | 1 byte | N bytes          | 1 byte | 1 byte |
+--------+--------+------------------+--------+--------+
```

- **CRC 为低字节在前**（Modbus 惯例），注意不要写反。
- 帧内字节间隔应 ≤ 1.5 个字符时间，帧间静默应 ≥ 3.5 个字符时间。
  9600 bps 下 1 个字符约 1.04 ms，即帧间静默 ≥ 约 3.7 ms。
- 本设备支持的功能码：**0x03**（读保持寄存器）、**0x06**（写单个寄存器）。
  不支持 0x01/0x02/0x04/0x05/0x0F/0x10。
- 说明书未定义广播地址（0）的行为，**不建议使用广播**。

### 3.1 读寄存器（功能码 0x03）

请求：

```
地址(1) | 0x03 | 起始寄存器高 | 起始寄存器低 | 寄存器数量高 | 寄存器数量低 | CRC低 | CRC高
```

响应：

```
地址(1) | 0x03 | 字节数(1) | 数据(2×N) | CRC低 | CRC高
```

其中 `字节数 = 2 × 寄存器数量`，响应总长度 = `5 + 2N` 字节。

### 3.2 写单个寄存器（功能码 0x06）

请求与响应格式相同，**响应原样回显请求**（8 字节），回显即代表写入成功：

```
地址(1) | 0x06 | 寄存器地址高 | 寄存器地址低 | 值高 | 值低 | CRC低 | CRC高
```

## 4. 寄存器映射

| 寄存器地址 | PLC/组态地址 | 功能 | 读写 | 功能码 | 说明 |
|---|---|---|---|---|---|
| `0x07D0` | 42001 (`0xA411`) | 设备地址 | R/W | 0x06 | 写入 1~247，立即生效且掉电保存 |
| `0x07D1` | 42002 (`0xA412`) | 波特率编码 | R/W | 0x06 | 编码见 4.1，立即生效且掉电保存 |
| `0x0100` | 40257 (`0x9D41`) | 气压 | R | 0x03 | uint16，单位 10 Pa |
| `0x0101` | 40258 (`0x9D42`) | 温度 **【实测】** | R | 0x03 | int16，单位 0.1 ℃ |
| `0xFE00` | — **【实测】** | 产品型号 | R | 0x03 | 见 4.2 |
| `0xFE01` | — **【实测】** | 软件版本 | R | 0x03 | 见 4.2 |

> 说明书 V2.1 的寄存器表只列了前 3 行（地址、波特率、气压）。
> 温度、型号、版本三项说明书未记载，是从厂家实测报文中整理出来的。

### 4.1 波特率编码

写入 `0x07D1` 的**寄存器值**（不是波特率本身）：

| 编码值 | 波特率 | 编码值 | 波特率 |
|---|---|---|---|
| 0 | 2400 | 4 | 38400 |
| 1 | 4800 | 5 | 57600 |
| 2 | **9600**（默认） | 6 | 115200 |
| 3 | 19200 | 7 | 1200 |

注意：编码 **0 是 2400 而不是 1200**，1200 在编码 7 上，容易记错。

### 4.2 型号与版本（调试用）

- **产品型号 `0x271B`** = 十进制 10011，按厂家编码规则拆成 `10` / `01` / `1`：
  `10` = RS485 接口，`01` = QY 系列，`1` = 气压 RS485 接口（BMP280 芯片）。
- **软件版本 `0x1902`**：高字节 `0x19` = 25（2025 年开始的软件），低字节 `0x02` = V2.0。

  > 厂家抓包里「单寄存器读版本」那条写作 `01 03 02 19 04 32 15`，是转录错误：
  > CRC `32 15` 只对报文 `01 03 02 19 02` 成立；同一份抓包里「读 2 个寄存器」那条
  > （CRC 有效）返回的也是 `19 02`。所以版本是 `0x1902`，厂家注释里的「V4.0」沿用了错字节。

## 5. 数据域含义

### 5.1 气压（`0x0100`）

- 类型：**uint16**，大端（高字节在前）
- 单位：**10 Pa**（即寄存器值 × 10 = Pa）
- 换算：

```
Pa   = raw × 10
hPa  = raw / 10
kPa  = raw / 100
```

| 寄存器值 | Pa | hPa | kPa |
|---|---|---|---|
| 9975 (`0x26F7`) | 99750 | 997.50 | 99.750 |
| 9974 (`0x26F6`) | 99740 | 997.40 | 99.740 |
| 10164 (`0x27B4`) | 101640 | 1016.40 | 101.640 |

- 输出的是**绝对气压**，不是相对大气压的表压；会随海拔与天气变化（海平面标准大气压约 1013.25 hPa）。
- 量程与精度：**说明书未标注**。芯片为 Bosch BMP280，其量程/精度请以芯片数据手册为准，
  不要直接引用到对外文档里当厂家指标。

### 5.2 温度（`0x0101`）**【实测】**

- 类型：int16（推测，实测样本均为正温，**负温行为【待确认】**），大端
- 单位：**0.1 ℃**，`温度(℃) = raw × 0.1`
- 示例：`0x0141` = 321 → 32.1 ℃

### 5.3 地址（`0x07D0`）

- 取值范围 1 ~ 247，写入后**立即生效**，后续通信必须使用新地址。
- **掉电保存**：厂家实测注明，断电或重新下载程序后新地址仍然保留。

### 5.4 波特率（`0x07D1`）

- 写入的是 4.1 节表格里的**编码值**，不是波特率数值。
- 写入后立即生效，**下次通信必须切换到新波特率**，否则会全部超时。

## 6. 报文示例

### 6.1 只读气压（1 个寄存器）

```
TX: 01 03 01 00 00 01 85 F6
RX: 01 03 02 26 F6 22 62
```

拆解：

| 字节 | 含义 |
|---|---|
| `01` | 从机地址 1 |
| `03` | 功能码：读保持寄存器 |
| `01 00` | 起始寄存器 `0x0100`（气压） |
| `00 01` | 读 1 个寄存器 |
| `85 F6` | CRC（低字节 `85` 在前） |

| 响应字节 | 含义 |
|---|---|
| `01` | 从机地址 |
| `03` | 功能码 |
| `02` | 后续数据 2 字节 |
| `26 F6` | 气压 raw = 9974 → 99740 Pa = 99.740 kPa |
| `22 62` | CRC |

### 6.2 同时读气压 + 温度（2 个寄存器，推荐）

```
TX: 01 03 01 00 00 02 C5 F7
RX: 01 03 04 26 F7 01 41 81 29
```

| 响应字节 | 含义 |
|---|---|
| `26 F7` | 气压 raw = 9975 → 99750 Pa = 997.50 hPa |
| `01 41` | 温度 raw = 321 → 32.1 ℃ |

一次请求拿到两个量，比分别读省一半总线往返。响应共 9 字节。

### 6.3 读取型号与版本

```
TX: 01 03 FE 00 00 02 F5 E3
RX: 01 03 04 27 1B 19 02 0A D1
```

`0x271B` = 型号，`0x1902` = 软件版本 V2.0。

### 6.4 修改地址为 2（`0x0001` → `0x0002`）

```
TX: 01 06 07 D0 00 02 08 86
RX: 01 06 07 D0 00 02 08 86     ← 原样回显即成功
```

之后必须用地址 `02` 访问：

```
TX: 02 03 01 00 00 02 C5 C4
RX: 02 03 04 26 F5 01 41 13 E9
```

### 6.5 修改波特率为 19200（编码 3）

```
TX: 01 06 07 D1 00 03 98 86
RX: 01 06 07 D1 00 03 98 86
```

之后所有通信切换到 19200 bps。

### 6.6 还原为 9600（编码 2）

```
TX: 01 06 07 D1 00 02 59 46
RX: 01 06 07 D1 00 02 59 46
```

## 7. CRC16 计算

标准 Modbus CRC16：多项式 `0xA001`（反射），初值 `0xFFFF`，**结果低字节先发送**。

Python 参考实现：

```python
def modbus_crc16(data: bytes) -> bytes:
    crc = 0xFFFF
    for b in data:
        crc ^= b
        for _ in range(8):
            crc = (crc >> 1) ^ 0xA001 if crc & 1 else crc >> 1
    return bytes((crc & 0xFF, (crc >> 8) & 0xFF))  # 低字节在前
```

校验向量（均取自厂家实测报文，可用于单元测试）：

| 数据（不含 CRC） | CRC 字节（低、高） |
|---|---|
| `01 03 01 00 00 01` | `85 F6` |
| `01 03 01 00 00 02` | `C5 F7` |
| `01 06 07 D0 00 02` | `08 86` |
| `01 06 07 D1 00 03` | `98 86` |
| `01 03 FE 00 00 02` | `F5 E3` |

## 8. 通信时序与轮询

- 9600 bps 下，1 个字符约 1.04 ms；9 字节响应在线上约 9.4 ms。
- 建议**响应超时 100 ~ 500 ms**，超时后重发；连续失败若干次判定设备离线。
- 建议**轮询间隔 ≥ 100 ms**，实际按需求取（气压变化慢，1 Hz 量级足够；厂家例程为 1 s）。
- RS-485 是半双工，同一时刻总线上只能有一个请求。多台设备挂同一总线时必须**串行轮询**，
  不同地址的请求之间要留出帧间静默。
- 设备上电后建议延迟 100 ~ 500 ms 再发第一帧，避开上电初始化。

## 9. 异常与边界情况

| 情况 | 表现 | 处理建议 |
|---|---|---|
| 地址不匹配 | 设备不应答（总线上其他设备正常） | 超时重试，之后判定离线 |
| CRC 错误 | 设备是否应答说明书未定义 | 主机端一律丢弃该帧并重试 |
| 不支持的寄存器地址 | 说明书未定义异常响应格式（是否回 `0x83` + 异常码未知） | 上线前实测确认，不要把异常帧当数据解析 |
| 未定义功能码 | 同上，说明书未定义 | 只用 0x03 / 0x06 |
| 数据长度不足 / 噪声帧 | 无 CRC 可校验 | 校验「地址 + 功能码 + 字节数 + 长度 + CRC」四项全对才采信 |
| 读到全 0 或越界值 | 可能是通信错误而非真实数据 | 结合 CRC 与量程合理性判断，不要把错误帧当 0 值使用 |

### 9.1 一个实测到的「地址别名」现象

厂家报文第 8 节里，PLC 把 **PLC 地址 40257（`0x9D41`）直接当作寄存器地址**发请求
（`01 03 9D 41 00 02 BB B3`），设备同样正常返回了气压与温度。

这说明固件可能对 `4xxxx` 形式的地址做了容错映射（`0x9D41 - 0x9C41 = 0x100`）。
**不建议依赖这个行为**：统一使用 `0x0100` / `0x0101` 这种协议地址，避免换批次固件后失效。

## 10. 一页速查

```
串口 : 9600 8N1（默认）   地址 : 1（默认）
读气压+温度 : 01 03 01 00 00 02 C5 F7
响应        : 01 03 04 <P_hi> <P_lo> <T_hi> <T_lo> <CRC_lo> <CRC_hi>
气压        : raw × 10  = Pa      raw / 100 = kPa
温度        : raw × 0.1 = ℃
改地址      : 01 06 07 D0 00 <addr> <CRC>
改波特率    : 01 06 07 D1 00 <code> <CRC>   (code: 2=9600, 3=19200)
CRC         : 标准 Modbus，多项式 0xA001，初值 0xFFFF，低字节先发
```
