# 485 协议与数据域

设备通过 RS-485 以 Modbus-RTU 提供气压与温度。本文描述帧格式、寄存器映射与数据域，
是 `ik_pressure_sensor` 编解码层（`ik_pressure_sensor/modbus_rtu.py`）的规范依据。

## 1. 链路参数

| 项 | 值 |
|---|---|
| 协议 | Modbus-RTU（半双工 RS-485） |
| 帧格式 | 8N1，固定 |
| 波特率 | 默认 9600，支持 8 档（见 4.3） |
| 从机地址 | 1 ~ 247，默认 1 |
| 功能码 | 0x03（读保持寄存器）、0x06（写单个寄存器） |

## 2. 帧格式

```
+--------+--------+------------------+--------+--------+
| 地址    | 功能码  | 数据域            | CRC 低  | CRC 高  |
| 1 byte | 1 byte | N bytes          | 1 byte | 1 byte |
+--------+--------+------------------+--------+--------+
```

- 无起始/结束符，帧边界由总线静默界定：帧内字节间隔 ≤ 1.5 个字符时间，
  帧间静默 ≥ 3.5 个字符时间（9600 bps 下约 3.7 ms）。
- **CRC 低字节在前**。
- 广播地址 0 的行为未定义，不要使用。

### 2.1 读寄存器（0x03）

```
请求: 地址 | 0x03 | 起始寄存器高 | 起始寄存器低 | 数量高 | 数量低 | CRC低 | CRC高
响应: 地址 | 0x03 | 字节数 | 数据(2×N) | CRC低 | CRC高
```

`字节数 = 2 × N`，响应总长 `5 + 2N` 字节。

### 2.2 写单个寄存器（0x06）

```
请求: 地址 | 0x06 | 寄存器地址高 | 寄存器地址低 | 值高 | 值低 | CRC低 | CRC高
响应: 与请求相同（原样回显即写入成功）
```

### 2.3 异常响应

设备拒绝请求时返回 5 字节异常帧：

```
地址 | 功能码 | 0x80 | 异常码 | CRC低 | CRC高
```

## 3. 寄存器映射

| 寄存器 | 功能 | 访问 | 数据域 |
|---|---|---|---|
| `0x0100` | 气压 | 读 | uint16，单位 10 Pa |
| `0x0101` | 温度 | 读 | int16，单位 0.1 ℃ |
| `0x07D0` | 从机地址 | 写 | 1 ~ 247，立即生效并掉电保存 |
| `0x07D1` | 波特率编码 | 写 | 见 4.3，立即生效并掉电保存 |
| `0xFE00` | 产品型号 | 读 | 见 4.4 |
| `0xFE01` | 软件版本 | 读 | 见 4.4 |

驱动只读取 `0x0100` 与 `0x0101`；配置寄存器列出仅为协议完整。

## 4. 数据域

### 4.1 气压（`0x0100`）

- 类型：uint16，大端
- 单位：10 Pa，`Pa = raw × 10`
- 输出的是**绝对气压**，随海拔与天气变化（海平面标准大气压约 1013.25 hPa）

| raw | Pa | hPa | kPa |
|---|---|---|---|
| 9975 (`0x26F7`) | 99750 | 997.50 | 99.750 |
| 9974 (`0x26F6`) | 99740 | 997.40 | 99.740 |
| 10164 (`0x27B4`) | 101640 | 1016.40 | 101.640 |

### 4.2 温度（`0x0101`）

- 类型：int16，大端
- 单位：0.1 ℃，`℃ = raw × 0.1`
- 示例：`0x0141` = 321 → 32.1 ℃；`0xFF9C` = −100 → −10.0 ℃

### 4.3 波特率编码

写入 `0x07D1` 的是编码值，不是波特率数值：

| 编码 | 波特率 | 编码 | 波特率 |
|---|---|---|---|
| 0 | 2400 | 4 | 38400 |
| 1 | 4800 | 5 | 57600 |
| 2 | **9600**（默认） | 6 | 115200 |
| 3 | 19200 | 7 | 1200 |

编码 0 对应 2400 而非 1200，1200 在编码 7。

### 4.4 型号与版本（`0xFE00` / `0xFE01`）

- 产品型号 `0x271B`：十进制 10011，编码 10 / 01 / 1，表示 RS-485 接口的 BMP280 气压产品
- 软件版本 `0x1902`：高字节 0x19 = 25（2025 年），低字节 0x02 = V2.0

## 5. 报文示例

读取气压与温度（推荐：一次往返取两个量）：

```
TX: 01 03 01 00 00 02 C5 F7
RX: 01 03 04 26 F7 01 41 81 29
    气压 raw = 0x26F7 = 9975 → 99750 Pa
    温度 raw = 0x0141 = 321  → 32.1 ℃
```

只读气压：

```
TX: 01 03 01 00 00 01 85 F6
RX: 01 03 02 26 F6 22 62        raw = 9974 → 99740 Pa
```

读取型号与版本：

```
TX: 01 03 FE 00 00 02 F5 E3
RX: 01 03 04 27 1B 19 02 0A D1   型号 0x271B，版本 0x1902
```

修改从机地址为 2：

```
TX: 01 06 07 D0 00 02 08 86
RX: 01 06 07 D0 00 02 08 86      回显即成功，此后使用地址 02
```

修改波特率为 19200（编码 3）：

```
TX: 01 06 07 D1 00 03 98 86
RX: 01 06 07 D1 00 03 98 86      此后通信切换到 19200
```

## 6. CRC16

标准 Modbus CRC16：多项式 `0xA001`（反射），初值 `0xFFFF`，结果低字节先发送。

```python
def modbus_crc16(data: bytes) -> bytes:
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            crc = (crc >> 1) ^ 0xA001 if crc & 1 else crc >> 1
    return bytes((crc & 0xFF, (crc >> 8) & 0xFF))  # 低字节在前
```

校验向量（数据不含 CRC）：

| 数据 | CRC 低、高 |
|---|---|
| `01 03 01 00 00 01` | `85 F6` |
| `01 03 01 00 00 02` | `C5 F7` |
| `01 06 07 D0 00 02` | `08 86` |
| `01 06 07 D1 00 03` | `98 86` |
| `01 03 FE 00 00 02` | `F5 E3` |

## 7. 时序

- 9600 bps 下 1 个字符约 1.04 ms，9 字节响应在线上约 9.4 ms
- 响应超时建议 100 ~ 500 ms，超时后重发
- 轮询间隔建议 ≥ 100 ms；气压变化慢，1 ~ 5 Hz 足够
- 半双工总线同一时刻只能有一个请求，多设备时必须串行轮询
- 上电后建议延迟 100 ~ 500 ms 再发第一帧

## 8. 异常与边界

| 情况 | 表现 | 主机处理 |
|---|---|---|
| 地址不匹配 | 无响应 | 超时后重试，多次失败判为离线 |
| CRC 不符 | 帧损坏 | 丢弃并重试 |
| 功能码或寄存器不支持 | 超时或 0x83 异常响应 | 丢弃，不要当作数据解析 |
| 长度不足或噪声帧 | 无法通过校验 | 校验「地址 + 功能码 + 字节数 + 长度 + CRC」全部通过才采信 |
| 数值明显越界 | 可能是通信错误 | 结合量纲合理性判断，不要把错误帧当 0 值使用 |

## 9. 速查

```
串口   9600 8N1（默认），从机地址 1（默认）
读气压+温度  01 03 01 00 00 02 C5 F7
响应         01 03 04 <P_hi> <P_lo> <T_hi> <T_lo> <CRC_lo> <CRC_hi>
气压         raw × 10 = Pa
温度         raw × 0.1 = ℃
改地址       01 06 07 D0 00 <addr> <CRC>
改波特率     01 06 07 D1 00 <code> <CRC>   (2 = 9600, 3 = 19200)
CRC          0xA001，初值 0xFFFF，低字节先发
```
