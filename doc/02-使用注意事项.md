# 艾克姆 RS485 气压变送器 —— 使用注意事项

> 面向实际接线、调试与接入上位机（含 Linux/ROS2）时容易踩的点。
> 协议细节见 [01-485协议与数据域.md](01-485协议与数据域.md)。

---

## 1. 供电与接线

- **传感器需要独立供电**（DC 5~30 V），RS-485 只走 A/B 两根信号线，
  USB 转 485 转换器一般不给传感器供电。接线前先确认电源从哪来。
- 说明书明确要求：**安装及接线过程中应断电操作**。
- 供电电压越高越抗线路压降：短线 5 V 可用，线缆较长时建议用 12 V 或 24 V。
- 电源端子有防反接设计，但仍建议上电前用万用表核对极性。
- 传感器与转换器若由不同电源供电、且距离较远，建议把两边 GND 共地；
  干扰大的现场直接用**带隔离的 USB-RS485 转换器**，省掉大量共模问题。
- 不要用 USB 口的 5 V 直接给传感器供电当长期方案（电流余量、纹波、共地都不理想），
  调试临时用可以，正式部署请用独立电源。

## 2. RS-485 总线

- **A/B 极性**：不同厂家的丝印常与通行约定相反，通信不上时**第一件事就是对调 A/B**，
  这是最省时间的排查动作（接反不会损坏设备）。
- 拓扑用**手拉手菊花链**，避免星形、避免长分支线；分支长度尽量控制在几十厘米内。
- **终端电阻**：短距离（几米）可以不加；线缆较长（>10 m）或波特率较高时，
  在总线**两端**各加 120 Ω，必要时加偏置电阻（很多转换器已内置，先看说明再加）。
- 屏蔽线屏蔽层**单点接地**，不要两端都接。
- 同一总线上的从机**地址必须唯一**（1~247）。地址 0 一般作广播，说明书未定义其行为，不要使用。
- 半双工总线同一时刻只能有一个请求；多机时**严格串行**，一问一答之间留帧间静默。
- 转换器要支持自动收发切换；若用的是带 RTS 的模块，需要注意方向控制时序，
  否则末字节可能被截断。

## 3. 参数配置

- **改地址/改波特率前先记录原值**。两个参数都是**立即生效且掉电保存**，
  改错之后只能靠上位机「搜索设备」逐个波特率 × 逐个地址去扫才能找回来。
- 一次只改一项，改完立刻用新参数验证通信，再改下一项。
- 波特率编码容易记错：**0 = 2400，2 = 9600，3 = 19200，7 = 1200**。
  写入的是编码值，不是波特率数值。
- 主机与设备必须完全同参数：波特率一致、**8N1 固定**。
- 没有多机需求时建议保持出厂默认（地址 1、9600），现场更换或返修时省事。

## 4. 数据使用

- 输出的是**绝对气压**，不是相对压差。海平面标准大气压约 1013.25 hPa，
  读数会随海拔、天气、空调环境变化，属正常。
- 用气压反算海拔时误差很大（天气变化就能带来几十米量级偏差），
  不要把它当精密高度计用。
- 单位换算是 `raw × 10 = Pa`，别和 `hPa`、`kPa` 混用；
  上层做阈值判断时先把单位统一固定下来。
- **温度寄存器说明书中未记载**（只在厂家实测报文里出现），
  正式使用前应在实机上确认：负温是否正确（有符号）、量程与分辨率是否如预期。
- **通信失败不能当作 0 值**参与计算或显示。只有「地址 + 功能码 + 字节数 + 帧长 + CRC」
  全部校验通过，且数值落在合理量程内，才认为这一帧有效。
- 气压读数本身有小幅抖动，直接拿去用会在曲线上看到毛刺；
  上层建议做滑动平均或一阶低通滤波。
- 不要用极高的频率轮询：传感器内部有转换/刷新周期，轮询比刷新率快只会拿到重复值，
  还白白占用总线。气压变化慢，1~5 Hz 已经足够。

## 5. 接入 Linux / ROS2 前的准备

- 常见 USB-RS485 转换器芯片为 CH340、FT232、CP210x，Linux 下通常枚举为 `/dev/ttyUSB*`。
  先用 `dmesg | tail` 确认设备识别与驱动加载正常。
- `/dev/ttyUSB0` 这类编号**会随插拔顺序变化**，正式部署建议用 udev 规则按序列号固定名字：

  ```
  # /etc/udev/rules.d/99-pressure-sensor.rules
  SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="7523", ATTRS{serial}=="<你的序列号>", SYMLINK+="pressure_sensor"
  ```

  然后用 `/dev/pressure_sensor` 访问。`idVendor/idProduct` 用 `lsusb` 查，序列号用
  `udevadm info -a -n /dev/ttyUSB0` 查。

- 串口权限：把运行节点的用户加入 `dialout` 组，**重新登录后生效**：

  ```
  sudo usermod -aG dialout $USER
  ```

- 同一个串口不能被两个进程同时打开；调试助手和节点不要一起开。
- 建议先用 `minicom` / `python -m serial.tools.miniterm` 之类工具手工发一帧
  `01 03 01 00 00 02 C5 F7` 确认能收到 9 字节响应，再去接上层节点。
- USB 转换器热插拔后设备名可能变化，节点需要能检测串口消失并自动重连，
  而不是启动失败后一直空跑。

## 6. 安装环境与维护

- 安装位置要远离化学腐蚀环境、高压电、热源和大振动源。
- 测的是**变送器壳体所处位置**的气压：不要装在被遮挡的密闭腔内，
  也不要贴着空调出风口或阳光直射处，否则测到的是局部环境而不代表被测空间。
- 外壳上的通风/导压孔不能被胶带、灰尘或保温材料堵住。
- 传感器属精密器件，**不要自行拆解**，拆解会损坏且失去保修。
- 存放环境要求干燥、通风、常温。
- 保修期为发货起 12 个月（非人为损坏免费维修/更换）。

## 7. 快速排障清单

| 现象 | 优先排查 |
|---|---|
| 完全无响应 | 供电是否正常 → A/B 是否接反 → 波特率/地址是否匹配 → 转换器驱动 → 串口是否被别的进程占用 |
| 有响应但校验不过 | 波特率偏差、线缆质量、接地/屏蔽、终端电阻、强干扰源 |
| 偶发丢帧 | 降低轮询频率、加超时重试、检查共地与屏蔽、加隔离转换器 |
| 数据偶尔跳变到异常值 | 干扰（变频器、继电器、电机）→ 加滤波/屏蔽；同时确认 CRC 校验没被绕过 |
| 改了地址/波特率后失联 | 用「搜索设备」按波特率 × 地址扫描找回 |
| 读数与预期差很多 | 确认是绝对气压、确认单位换算、确认安装位置未被局部环境影响 |
